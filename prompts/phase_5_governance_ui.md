# AntiGravity Prompt: Phase 5 — Governance UI

## Context
Build Next.js 15 dashboard for inspecting and governing Acumius.

## Your Task

### 1. Scaffold
Next.js 15 + TypeScript + Tailwind + shadcn/ui + TanStack Query + Recharts.

### 2. Screens
- /memories — Memory Explorer (table, search, filter, edit)
- /agents — Agent Directory (cards, reputation, history)
- /policies — Policy Editor (YAML editor, validation, test)
- /audit — Audit Log (real-time SSE, filter, export)
- /gdpr — GDPR Tools (forget, export, rectify)
- / — Dashboard (metrics, charts, activity)

### 3. Auth
Simple API key login, stored in localStorage.

### Acceptance Criteria
- [ ] All 6 screens functional
- [ ] Real-time audit streaming
- [ ] Policy editor with validation
- [ ] GDPR workflows < 3 clicks
- [ ] Dashboard shows live metrics
